# b003g design: practise standing 5% of the time, as the menus always said (pre-registered 2026-10-02)

## Why
Every run from b003 to b003f asked for `rel_standing_envs: 0.05` and trained at 25%. VelStand's
`standing_envs` curriculum rewrites the share on every reset from its own stages
(`[{step: 0, rel_standing_envs: 0.25}]`), and TensorBoard's `Curriculum/standing_envs` read 0.25
throughout (b003d close). A quarter of all practice was "do not move", and the walk/recovery
evaluation scores standing as tracking. That is the last named confound in the practice mix
that no run has changed.

## Method (the one change from b003f)
- The menu key `standing_envs: 0.05` replaces the curriculum's stages with a single stage at
  0.05 (`finetune.py`). The term still runs and still logs `Curriculum/standing_envs`. The CPU
  smoke run logged 0.0500 on both iterations, where earlier runs logged 0.25.
- Everything else is b003f's:
  - the upright anchor off and the recovery anchor kept;
  - mjlab's tracking terms plus the progress terms;
  - warm start from b002's a02;
  - 1,500 iterations × 2,048 envs on l4x1.
- **Built on b003f, not b003b.** Turning the anchor off cost nothing measured (falls 0.40,
  recovery 99.6%) and freed turning, so it stays on.

## Pass lines, written before the result (b003's, unchanged)
1. Dead band: cmd 0.10 m/s → ≥ 0.05 m/s; cmd 0.05 → ≥ 0.02.
2. Turn on the spot: wz 1.0 → ≥ 0.5 rad/s.
3. Nothing broken: falls/min ≤ 0.71; recovery within 10 points of the teacher; planar error
   ≤ 0.179.
4. cmd 0.30 m/s → ≥ 0.12 m/s.
- M. Mechanism bar: cmd 0.10 → ≥ 0.02 m/s on the 512-env curve.
- **Also logged, not a line:** `Curriculum/standing_envs` must read 0.05 throughout. If it does
  not, the run did not test this change and is void.

## Expectation to beat
- **I give the mechanism bar about one in four.** Less standing practice removes a reason to
  stand. But b003c showed that standing pays well at small commands even with plenty of
  practice there, and nothing here changes the start: a network that has never stepped below
  0.15 m/s.
- **Risk: holding still.** Fewer standing envs may cost the ability to stand when told to. The
  speed curve has no zero command, so I will read stand drift (planar speed at cmd 0) from the
  walk/recovery evaluation's standing envs, and report it.
- **Turning** should hold near b003f's 0.806. Falls are the line to watch.
- **If the band still does not move,** fine-tuning this student is the wrong start. The next run
  is from scratch, or a longer run from b003f@1000, and is a different kind of experiment.
